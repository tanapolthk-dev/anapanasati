# โฟลเดอร์ไฟล์เสียงสวดมนต์

วางไฟล์เสียงสวดที่ **บันทึกเสียงเอง** หรือ **ได้รับอนุญาตให้ใช้เป็นลายลักษณ์อักษร** ไว้ที่นี่ (แนะนำ .mp3 ขนาดไม่เกิน 3 MB ต่อไฟล์)

จากนั้นเปิด `index.html` ค้นหา `chantAudio` แล้วเพิ่มบรรทัด เช่น

```js
chantAudio: {
  namo: 'audio/namo.mp3',
  itipiso: 'audio/itipiso.mp3',
},
```

รหัสบทสวดที่ใช้ได้: `bucha`, `namo`, `trisarana`, `itipiso`, `sangkhara`, `metta-self`, `metta-all`, `kruat`

ปุ่ม "ฟังเสียงสวด" จะปรากฏในหน้าบทสวดนั้นโดยอัตโนมัติ

> ห้ามนำไฟล์เสียงจาก YouTube แอปอื่น หรือซีดีที่มีลิขสิทธิ์มาใส่โดยไม่ได้รับอนุญาต ตัวบทสวดภาษาบาลีเป็นสาธารณสมบัติ แต่ "เสียงที่บันทึก" มีเจ้าของลิขสิทธิ์เสมอ
